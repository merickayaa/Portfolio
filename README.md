## Türkçe

Kendimi, ilgi alanlarımı ve projelerimi tanıttığım kişisel portfolyo sitesi.

### İçerik

Site tek sayfadan oluşur ve şu bölümleri içerir:

- **Anasayfa** – Karşılama ekranı ve profil fotoğrafı
- **Hakkımda** – Kişisel bilgiler, eğitim ve bildiğim teknolojiler
- **Hobilerim & İlgilerim** – Gym, yürüyüş, bilgisayar oyunları
- **Projelerim** – Geliştirdiğim projeler
- **Bağlantılar** – LinkedIn ve GitHub profillerim

### Projeler

| Proje | Açıklama | Bağlantılar |
|-------|----------|-------------|
| **BAUN Media** | Django ile geliştirdiğim sosyal medya sitesi | [Canlı site](http://baun-media.eu-north-1.elasticbeanstalk.com/) · [Kaynak kod](https://github.com/merickayaa/Django-Social-Media) |

### Kullanılan Teknolojiler

- HTML5
- CSS3
- [Bootstrap 5](https://getbootstrap.com/)
- JavaScript

### Çalıştırma

Proje herhangi bir kurulum gerektirmez.

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/merickayaa/Portfolio.git
   ```
2. `index.html` dosyasını tarayıcıda açın.

### Klasör Yapısı

```
Portfolio/
├── index.html    # Sitenin tamamı (HTML, stil ve script)
└── resimler/     # Sitede kullanılan görseller
```
